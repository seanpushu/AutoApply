# Summer 27 投递助手

Chrome / Edge 本地扩展。打开 chrome://extensions 或 edge://extensions，开启开发者模式，选择“加载已解压的扩展程序”，加载这个含 manifest.json 的文件夹。

完整中文说明见工作台 /application-helper-guide.html。

工作台 Application desk 选岗 → 选择实际简历并导出申请包 → 在雇主完整表单页主动打开助手并导入 → 确认预填与上传 → 原网页完成剩余项目 → 读取表单 → 逐份核对、确认并提交 → 核实雇主回执 → 导出回执到工作台导入。

支持可识别的 Ashby / Greenhouse / Lever 原生表单；特殊页面需要手动处理。登录、验证码、工作授权、赞助、敏感问题和求职动机由本人逐岗填写。上传文件也可能立即向雇主传送资料，预填前有独立确认。

仅 activeTab 和 scripting 权限，无后台任务、模型 API 或自动跨站扫描。申请资料保存在本机扩展数据库。点击提交只记录尝试，看到雇主回执并手动确认后才记录成功；已有尝试不自动重复提交。测试使用模拟表单，未向真实雇主提交申请。
